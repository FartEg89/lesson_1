1. 🗣️ Языки программирования. Развитие языков программирования

Представьте, что вы хотите объяснить роботу, как приготовить чай. Человеку достаточно сказать: «Сделай чай». Компьютеру нужно сообщить практически каждое действие в понятной для него форме. Язык программирования — это язык, на котором человек записывает инструкции для компьютера.
📝 ЗАПИШИТЕ В ТЕТРАДЬ

Язык программирования — это формальный язык, предназначенный для записи алгоритмов и программ, которые может выполнять компьютер.

Что означает слово «формальный»?

Формальный — значит строго определённый. У языка есть правила написания команд, слов и конструкций.

Например, в разговорной речи можно сказать: «Посчитай сумму двух чисел». Программе такую мысль нужно записать в правилах конкретного языка. 

# Python
a = 10
b = 20
summa = a + b
print(summa)

Почему языков программирования так много?

Потому что разные задачи требуют разных инструментов. Нельзя одним языком одинаково удобно писать операционную систему, веб-сайт, мобильное приложение и программу для анализа данных.

💡 ВАЖНО

Язык программирования — это инструмент. Хороший программист не обязан знать все языки. Важно понимать принципы программирования и уметь выбирать подходящий инструмент под задачу.

Короткая история развития

Период Что происходило Примеры
1-е поколение Машинные коды: команды записываются непосредственно в виде двоичных инструкций. Машинный язык
2-е поколение Появляется ассемблер. Вместо числовых кодов используются условные обозначения команд. Assembly
3-е поколение Появляются языки высокого уровня. Программы становятся ближе к человеческому мышлению. Fortran, Pascal, C, C++, Java, Python
4-е поколение Языки и средства, ориентированные на решение конкретных задач и работу с данными. SQL, MATLAB, специализированные 4GL
5-е поколение Попытки описывать задачу преимущественно через правила, ограничения и логическое описание. Prolog и другие логические подходы
⚠️ ВАЖНО ПРО «ПОКОЛЕНИЯ»

Деление языков на поколения — это историческая классификация. В современных курсах её используют прежде всего для понимания того, как развивались способы общения человека с компьютером.

От машинных кодов к языкам высокого уровня

Машинный язык

Компьютеру очень понятен, человеку — крайне неудобен. Инструкции представлены в форме, близкой к машинным кодам.

Язык высокого уровня

Человеку значительно проще читать и писать. Примеры: Python, C++, Pascal.

🌱 ПРИМЕР ИЗ ЖИЗНИ

Представьте переводчика. Один человек говорит по-русски, другой понимает только английский. Чтобы они договорились, нужен переводчик.

Похожая идея существует между человеком и компьютером: программист пишет программу на языке программирования, а специальные средства переводят или выполняют эти инструкции.

2. 🌐 Обзор языков программирования. Области применения. Стандарты

Нож нужен не для всего сразу: им можно резать хлеб, но им неудобно забивать гвозди. Точно так же разные языки программирования лучше подходят для разных задач.
📝 ЗАПИШИТЕ В ТЕТРАДЬ

Область применения языка программирования — это класс задач, для которых данный язык используется наиболее удобно и эффективно.

Какие языки стоит знать хотя бы на базовом уровне?

💡 ЯЗЫК НЕ РАВЕН ПРОГРАММИРОВАНИЮ

Знать синтаксис языка недостаточно. Программирование включает алгоритмы, структуры данных, проектирование, тестирование и отладку.

Что такое стандарт языка?

📝 ЗАПИШИТЕ В ТЕТРАДЬ

Стандарт языка программирования — это официально установленное описание правил языка, его конструкций и их поведения.

Стандарт помогает разработчикам программ и создателям компиляторов понимать язык одинаково.

Стандарт и конкретная программа — не одно и то же

Например, стандарт определяет, какие конструкции должен поддерживать язык. А конкретный компилятор или интерпретатор реализует эти правила в реальной программе.

Язык

Набор правил: как писать программу и что означают конструкции.

Реализация языка

Конкретный инструмент, который позволяет запускать программы: компилятор, интерпретатор или другая среда выполнения.

🌱 ПРИМЕР ИЗ ЖИЗНИ

Представьте правила дорожного движения. Они определяют, что означает красный свет, знак STOP, пешеходный переход и т. д.

Конкретный автомобиль может отличаться маркой и моделью, но правила движения остаются общими. Стандарт языка работает примерно так же: правила языка одни, а реализации могут быть разными.

3. 🛠️ Среда проектирования — IDE

Представьте мастерскую. В ней есть стол, инструменты, освещение, ящики для материалов и место для сборки. IDE — это цифровая мастерская программиста.
📝 ЗАПИШИТЕ В ТЕТРАДЬ

IDE (Integrated Development Environment) — интегрированная среда разработки, то есть программа, объединяющая инструменты для создания, запуска, тестирования и отладки программ.

Что обычно входит в IDE?

Инструмент Зачем нужен
Редактор кода Писать и изменять программу.
Подсветка синтаксиса Разделять команды, строки, числа и другие элементы разными визуальными признаками.
Автодополнение Подсказывать названия команд и конструкций.
Отладчик Искать ошибки и пошагово выполнять программу.
Терминал Выполнять команды операционной системы и запускать программы.
Система сборки Автоматизировать компиляцию и другие действия с проектом.

Примеры IDE и редакторов

Visual Studio

Мощная среда разработки, особенно популярная для C# и C++.

PyCharm

IDE, ориентированная прежде всего на разработку на Python.

IntelliJ IDEA

Популярная среда разработки, особенно в экосистеме Java и JVM.

Visual Studio Code

Очень популярный редактор с расширениями, позволяющими превратить его в мощную среду разработки.

💡 ВАЖНО

IDE не является языком программирования. Например, Python — язык, а PyCharm — среда разработки, в которой удобно писать программы на Python.

🌱 ПРИМЕР ИЗ ЖИЗНИ

Повар может работать только с ножом. Но гораздо удобнее иметь целую кухню: нож, плиту, духовку, холодильник и рабочую поверхность.

Программист тоже может писать код в простом текстовом редакторе, но IDE объединяет множество инструментов в одном месте.

4. ⚙️ Компиляторы и интерпретаторы

Представьте переводчика. Он может сначала полностью перевести книгу, а потом выдать её читателю. А может переводить речь почти сразу, предложение за предложением. В программировании существуют похожие подходы: компиляция и интерпретация.
📝 ЗАПИШИТЕ В ТЕТРАДЬ

Компилятор — программа, которая переводит исходный код программы в другую форму, обычно с последующим получением выполняемого или промежуточного представления.

Интерпретатор — программа или механизм выполнения, который читает исходный или промежуточный код и выполняет его с использованием среды выполнения.

Главное различие

Компилятор Интерпретатор
Обычно сначала переводит программу в другое представление. Обычно выполняет программу в процессе её обработки.
Может заранее обнаружить много ошибок в коде. Некоторые ошибки становятся заметны при достижении соответствующего места выполнения.
После успешной компиляции программу можно запускать отдельно от исходного текста, если получен соответствующий исполняемый результат. Для выполнения может требоваться среда интерпретации или виртуальная машина.
⚠️ ВАЖНО

В реальных современных языках граница между «компилируемым» и «интерпретируемым» языком не всегда такая простая. Многие системы используют несколько этапов: компиляцию, промежуточный код, виртуальную машину и JIT-компиляцию.

Пример: Python

Python часто называют интерпретируемым языком. На практике реализация CPython сначала переводит исходный код в байт-код, а затем выполняет его виртуальной машиной Python.

Пример: C++

C++ обычно компилируется. Компилятор преобразует исходный код в объектный код и затем программа связывается с библиотеками. 

// C++
#include <iostream>

int main() {
    std::cout << "Hello!";
    return 0;
}

Пример: Pascal

Классический Pascal также относится к компилируемым языкам: исходный текст переводится компилятором в форму, пригодную для выполнения.

🌱 ПРИМЕР ИЗ ЖИЗНИ

Компилятор можно представить как переводчика, который получает инструкцию, полностью переводит её и отдаёт готовую версию.

Интерпретатор больше похож на переводчика-синхрониста: он помогает выполнять инструкции непосредственно в процессе работы.

5. 🔄 Жизненный цикл программы. Программа и программный продукт

Когда строят дом, не начинают с установки люстры. Сначала определяют, что строить, делают проект, подбирают материалы, строят, проверяют результат, а затем дом обслуживают. С программами происходит очень похожий процесс.
📝 ЗАПИШИТЕ В ТЕТРАДЬ

Программа — это последовательность команд, записанная на языке программирования и предназначенная для выполнения компьютером.

Программный продукт — это программное средство, созданное для решения определённых задач пользователя и сопровождаемое необходимыми компонентами и документацией.

Программа и программный продукт — не совсем одно и то же

Программа Программный продукт
В первую очередь — код и выполняемые инструкции. Программа + необходимые файлы, интерфейс, документация, настройки и другие компоненты.
Может быть очень маленькой. Обычно рассчитан на реального пользователя и практическое применение.

Основные характеристики программного продукта

Функциональность

Продукт должен выполнять необходимые пользователю функции.

Надёжность

Программа должна работать стабильно и предсказуемо.

Удобство использования

Пользователь должен понимать, как работать с системой.

Производительность

Программа должна выполнять работу с приемлемой скоростью и расходом ресурсов.

Безопасность

Программа должна защищать данные и ограничивать опасные действия.

Сопровождаемость

Программу должно быть возможно исправлять и развивать.

🔄 Жизненный цикл программы

Жизненный цикл — это путь программного продукта от возникновения идеи до эксплуатации, обновлений и завершения использования.

1 Анализ требований

Определяем, что нужно пользователю и какую проблему решаем.

↓
2 Проектирование

Продумываем структуру будущей программы.

↓
3 Разработка

Пишем код и создаём необходимые компоненты.

↓
4 Тестирование

Проверяем, работает ли программа правильно.

↓
5 Внедрение

Продукт передают пользователям и вводят в эксплуатацию.

↓
6 Сопровождение

Исправляем ошибки, обновляем программу и добавляем новые возможности.

💡 ВАЖНО

Жизненный цикл не заканчивается после написания кода. Большая часть реальной работы над программным продуктом связана с тестированием, исправлениями, обновлениями и сопровождением.

🌱 ПРИМЕР ИЗ ЖИЗНИ

Представьте мобильное приложение для расписания колледжа.

Сначала кто-то замечает проблему: «Студентам неудобно узнавать расписание». Затем определяют требования, проектируют приложение, программируют, тестируют, публикуют и позже исправляют ошибки и добавляют новые функции.

6. 🧩 Основные этапы решения задач на компьютере

Прежде чем отправиться в путешествие, вы сначала решаете, куда ехать, изучаете маршрут и только потом садитесь в машину. Решение задачи на компьютере происходит похожим образом: сначала думаем, потом записываем алгоритм, затем программируем.
📝 ЗАПИШИТЕ В ТЕТРАДЬ

Алгоритм — это конечная последовательность понятных и выполнимых действий, приводящая к решению задачи.

Схема решения задачи

1.
Постановка задачи
2.
Анализ
3.
Алгоритм
4.
Программа
5.
Проверка

При необходимости: исправление → повторная проверка

1. Постановка задачи

Нужно точно понять, что требуется получить.

❗ Главный вопрос

Что дано? → Что нужно получить?

2. Анализ задачи

Определяем исходные данные, результат, ограничения, необходимые формулы и зависимости.

3. Разработка алгоритма

Продумываем последовательность действий. Алгоритм можно записать словами, псевдокодом или представить в виде блок-схемы.

4. Программирование

Переводим алгоритм на конкретный язык программирования.

5. Тестирование и отладка

Проверяем программу на различных данных. Если результат неверный — ищем и исправляем ошибку.

6. Использование решения

После проверки программу можно использовать для решения реальной задачи. 

# Небольшой пример: вычисление стоимости покупки

price = 500
quantity = 3

total = price * quantity

print(total)

Перед написанием этого кода мы должны были сначала решить: какие данные известны, что требуется вычислить и как получить результат.

🌱 ПРИМЕР ИЗ ЖИЗНИ

Допустим, вам нужно приготовить ужин для пяти человек.

Вы сначала решаете, что приготовить, затем определяете необходимые продукты, составляете порядок действий, готовите блюдо и пробуете результат.

Если суп пересолен — вы исправляете проблему. Это и есть очень бытовая аналогия анализа, алгоритма, выполнения и отладки.

7. 🧱 Типы данных: простые, производные, структурированные

Представьте шкаф с вещами. Нельзя складывать обувь, документы, книги и жидкость в одну и ту же коробку без правил. Компьютеру тоже нужно знать, какие именно данные хранятся и как с ними работать.
📝 ЗАПИШИТЕ В ТЕТРАДЬ

Тип данных — это характеристика данных, определяющая, какие значения они могут принимать, сколько памяти занимают и какие операции над ними допустимы.

Зачем вообще нужны типы?

Если компьютер видит число, он понимает, что с ним можно выполнять арифметические операции.

Если это строка, с ней выполняются другие операции: объединение текста, поиск символов, сравнение и т. д.

Число

25 + 10

Строка

"25" + "10" → текстовая операция, а не обычное сложение чисел.

Основные группы типов данных

Группа Что содержит Примеры
Простые Одно отдельное значение. целое число, вещественное число, символ, логическое значение
Производные Типы, построенные на основе других типов. указатели, ссылки, некоторые производные конструкции конкретного языка
Структурированные Объединяют несколько значений в одну структуру. массив, запись/структура, список, множество

1. Простые типы

Простые типы представляют одно значение.

Тип Пример значения Смысл
Целый 15 Целое число без дробной части.
Вещественный 3.14 Число с дробной частью.
Символ 'A' Один отдельный символ.
Логический true / false Истина или ложь.

2. Производные типы

Производный тип создаётся на основе другого типа или типов и добавляет новые способы представления и работы с данными.

Например, в C++ можно создать ссылку или указатель на существующий тип. 

int age = 18;

int* ptr = &age;

Здесь int — базовый тип, а int* — указатель на значение типа int.

💡 НЕ ПУТАЙТЕ

Классификация типов может немного различаться между языками. Поэтому всегда нужно учитывать конкретный язык программирования. Например, Python использует динамическую типизацию, а C++ и Pascal имеют более явно выраженную систему типов.

3. Структурированные типы

Структурированный тип объединяет несколько значений, связанных между собой.

Массив

Массив позволяет хранить набор однотипных элементов. 

// C++
int numbers[5] = {10, 20, 30, 40, 50};

Запись / структура

Структура позволяет объединить разные по смыслу данные в один объект. 

// C++
struct Student {
    std::string name;
    int age;
};

Списки

Список — последовательность элементов, с которой можно выполнять различные операции: добавление, удаление, поиск и т. д. 

# Python
students = ["Анна", "Иван", "Олег"]

Сравним типы на простом примере

Что хотим хранить Подходящий тип
Возраст человека Целое число
Средний балл Вещественное число
Пол студента в форме одного символа Символ
Сдан экзамен или нет Логический тип
Список оценок Массив / список
Информация о студенте Структура / запись / объект

📋 Краткое резюме лекции

  1. Язык программирования — формальный язык для записи алгоритмов и программ.
  2. Языки программирования развивались от машинных кодов к языкам высокого уровня.
  3. Разные языки подходят для разных задач: Python, C++, Pascal, Java, JavaScript, C# и другие.
  4. Стандарт языка задаёт правила, которые описывают его конструкции и поведение.
  5. IDE — цифровая мастерская программиста, объединяющая редактор кода, запуск, отладку и другие инструменты.
  6. Компилятор переводит исходный код в другое представление, предназначенное для дальнейшего выполнения.
  7. Интерпретатор выполняет программу через механизм интерпретации во время работы.
  8. Программа — последовательность команд для компьютера, а программный продукт включает программу и необходимые пользователю компоненты.
  9. Жизненный цикл программы включает анализ требований, проектирование, разработку, тестирование, внедрение и сопровождение.
  10. Решение задачи начинается не с написания кода, а с понимания задачи и разработки алгоритма.
  11. Тип данных определяет, какие значения можно хранить и какие операции над ними допустимы.
  12. Типы данных можно рассматривать как простые, производные и структурированные; конкретная классификация зависит от языка.

📝 Словарь терминов

Алгоритм — конечная последовательность понятных и выполнимых действий для решения задачи.
Язык программирования — формальный язык для записи алгоритмов и программ.
Машинный язык — язык, инструкции которого представлены в форме, непосредственно связанной с машинными командами.
Ассемблер — язык низкого уровня, использующий символьные обозначения машинных инструкций.
Язык высокого уровня — язык, синтаксис и конструкции которого ориентированы на удобство человека.
Стандарт языка — официальное описание правил языка, его конструкций и их поведения.
IDE — интегрированная среда разработки, объединяющая инструменты создания программ.
Редактор кода — инструмент для написания и изменения исходного кода.
Отладчик — инструмент для поиска и анализа ошибок программы.
Компилятор — программа, преобразующая исходный код в другое представление для дальнейшего выполнения.
Интерпретатор — механизм или программа, выполняющая код во время его обработки.
Программа — последовательность команд, предназначенная для выполнения компьютером.
Программный продукт — программное средство для решения задач пользователя вместе с необходимыми компонентами.
Жизненный цикл программы — совокупность этапов существования программного продукта от идеи до сопровождения и завершения использования.
Требования — описание того, что должна делать программа и какие условия она должна выполнять.
Проектирование — разработка структуры и устройства будущей программы.
Разработка — создание программы, включая написание кода.
Тестирование — проверка программы на правильность и соответствие требованиям.
Отладка — поиск и исправление ошибок в программе.
Сопровождение — исправление, обновление и развитие программы после выпуска.
Тип данных — характеристика данных, определяющая допустимые значения и операции над ними.
Простой тип — тип, представляющий одно отдельное значение.
Производный тип — тип, построенный на основе другого типа или типов.
Структурированный тип — тип, объединяющий несколько значений в одну структуру.
Массив — структура данных для хранения набора элементов, обычно одного типа.
Структура / запись — объединение нескольких связанных полей, которые могут иметь разные типы.
Логический тип — тип, принимающий логические значения, например истина и ложь.
Целый тип — тип для хранения целых чисел.
Вещественный тип — тип для хранения чисел с дробной частью.
Символьный тип — тип для хранения отдельного символа.
Строка — последовательность символов, используемая для представления текста.
